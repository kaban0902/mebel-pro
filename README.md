# MEBEL-PRO.KZ

Статический адаптивный лендинг. HTML, CSS и JavaScript; сборка и установка зависимостей не нужны.

## Запуск

Откройте `index.html` или запустите локальный сервер из папки проекта:

```sh
python -m http.server 8080 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:8080

## Публикация

Загрузите `index.html`, `styles.css`, `quiz.css`, `mobile.css`, `script.js`, `quiz.js`, `favicon.ico`, `robots.txt`, `sitemap.xml`, `logo.jpeg` и папку `assets` на статический хостинг с HTTPS для `mebel-pro.kz`. Папки `qa`, `scripts` и исходные `custom-*` публиковать не требуется. Если меняется домен, обновите canonical, Open Graph, JSON-LD, sitemap и robots.

## Фотографии

Исходные фотографии сохранены без изменений. Для сайта подготовлены WebP шириной до 480, 800 и 1280 px; ниже первого экрана — ленивая загрузка. `scripts/prepare_assets.py` воспроизводит оптимизированные файлы с помощью Pillow и загружает Manrope для локального размещения. Шрифт работает без запросов посетителя к Google.

Каталог содержит шесть категорий с реальными фотографиями: кухни, детские, гостиные, ванные, прихожие и гардеробные. Каждая карточка использует адаптивные WebP-версии изображения и тематическую ссылку для расчёта в WhatsApp. На ширине до 768 px каталог и проекты листаются горизонтально; квиз показан перед проектами, а после hero доступна нижняя кнопка перехода к расчёту.

## Контакты и содержание

Контактные данные и ссылки находятся в `index.html`. Общие WhatsApp-ссылки используют номер `77774122475` и сообщение «Здравствуйте! Хочу рассчитать стоимость мебели.». У категорий и проектов есть тематические сообщения. Год в подвале обновляется автоматически; FAQ и мобильное меню работают с клавиатуры.

Блок расчёта перед этапами работы содержит четыре вопроса. Только после ответов он формирует ссылку WhatsApp с выбранными данными через encodeURIComponent; на сайте стоимость не вычисляется. События quiz_started, quiz_answered, quiz_completed и whatsapp_calculation_clicked доступны через CustomEvent и существующий dataLayer, если он подключён.

`qa` содержит результаты проверок и снимки экранов; они не нужны для работы сайта.
